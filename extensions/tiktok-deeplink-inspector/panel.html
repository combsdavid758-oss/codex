Draft deeplink test

This inspector does not enable an unsupported ad destination. It reads selected link fields from requests while you save a draft. It never edits requests or publishes ads.

Inspect a draft save

  1. Open Ads Manager and edit a draft. Keep this DevTools panel open.
  2. Click Start capture, then save the draft using TikTok's editor. Do not launch an ad.
  3. Stop capture. Look for a native deeplink field and compare a draft that supports it with your website-only draft.
  4. If no relevant fields appear, the request may use another encoding. No result does not establish that deeplinks are unsupported.

Only matching link fields and their JSON paths are displayed. Headers, cookies, response bodies and unrelated fields are excluded. Links can still contain tracking identifiers: review before sharing.
